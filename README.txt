ORBIX ELEVATORS — HTML, CSS & JAVASCRIPT ONLY

Static frontend package: HTML pages, CSS/compiled styling, JavaScript interactions, and supplied image/video assets. No backend, database, API server, React, Vite, Node dependencies, or build step.

RUN LOCALLY:
1. Extract this folder.
2. Open the folder in VS Code.
3. Recommended: use the Live Server extension and click “Go Live” while index.html is open.
4. Alternatively, open index.html directly in a browser. Some browser security rules may limit certain effects when opened as a file.

MAIN PAGES: index.html, about.html, contact.html, gallery.html, products.html, projects.html, services.html.
Individual product, project, and service pages are in their matching subfolders.

Contact/enquiry interactions are frontend-only. No submitted data is saved to a server. Static pages reference /assets/ for compiled assets, so run Live Server from this folder as the web root.
